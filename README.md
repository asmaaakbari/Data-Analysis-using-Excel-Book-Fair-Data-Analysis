# Book Fair Data Analysis Dashboard

## Overview
This is my first data analysis project using Microsoft Excel.
The project analyzes book fair data to identify sales performance, visitor trends, and publisher insights.

## Tool Used
- Microsoft Excel

## Dashboard Features
- Total revenue analysis
- Total books sold
- Visitor analysis
- Publisher performance
- Sales by category
- Interactive filters

## Key Insights
- Analyzed sales distribution across book categories.
- Compared publisher performance.
- Studied visitor trends during the exhibition period.

## Skills Learned
- Data cleaning
- Pivot Tables
- Data visualization
- Dashboard creation
